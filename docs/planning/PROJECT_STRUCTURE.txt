==============================================
WORKING DIRECTORIES
==============================================

TO START DEVELOPMENT:

1. Root Level:
   npm install          (installs workspaces)

2. Backend:
   cd backend
   npm install
   cp .env.example .env (edit with your creds)
   npm run dev

3. Frontend:
   cd frontend
   npm install
   npm run web:dev      (web)
   OR
   npm run mobile:start (mobile)
